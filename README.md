# Minecraft Block Game

A simple **Minecraft-style block game** built using **JavaScript and Three.js**.
This project demonstrates how a voxel world works using cubes (blocks) arranged in a 3D grid.

---

## Features

* 3D block rendering
* Simple voxel world
* Camera movement
* Basic terrain generation
* Lightweight and beginner-friendly code

---

## Technologies Used

* JavaScript
* Three.js (3D graphics library)
* HTML5
* WebGL

## How It Works

The world is created using **cubes (blocks)**.

Each block is positioned using **3D coordinates**:

```
(x, y, z)
```

Example:

```
(0,0,0)
(1,0,0)
(2,0,0)
```

These blocks together create a **voxel terrain** similar to Minecraft.
